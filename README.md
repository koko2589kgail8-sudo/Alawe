# INK BATTLE — معركة الأقلام

لعبة متصفح جماعية لحظية تعمل على الجوال والكمبيوتر باستخدام Node.js وSocket.IO.

## تشغيل محلي
1. ثبّت Node.js 18 أو أحدث.
2. افتح مجلد المشروع في الطرفية.
3. نفّذ `npm install`.
4. نفّذ `npm start`.
5. افتح `http://localhost:3000`.

## نشر اللعبة على الإنترنت (Render)
ملف `render.yaml` جاهز لإعداد خدمة الويب تلقائياً.

1. أنشئ حساباً في GitHub وارفع محتويات هذا المجلد إلى مستودع جديد.
2. افتح https://render.com وسجّل الدخول.
3. اختر **New** ثم **Blueprint**، واربط مستودع GitHub الذي رفعت إليه المشروع.
4. وافق على إنشاء الخدمة `ink-battle` من ملف `render.yaml`.
5. انتظر حتى تنتهي عملية النشر، ثم افتح رابط `onrender.com` الذي يظهر لك.
6. أرسل الرابط إلى أصدقائك. عند إنشاء غرفة، استخدم زر **نسخ رابط الدعوة** لمشاركة رابط يتضمن رمز الغرفة ويدخل الصديق إليها مباشرة.

ملاحظة: خطة الاستضافة المجانية قد توقف الخدمة مؤقتاً عند عدم الاستخدام، وقد يستغرق أول فتح بعد الخمول بعض الوقت. الغرف محفوظة في ذاكرة الخادم؛ لذلك تختفي الغرف عند إعادة تشغيل الخدمة أو نشر تحديث.

## قواعد اللعبة
- سعة الغرفة من لاعبين إلى 20 لاعباً، ويمكن اختيار أي رقم ضمن هذا النطاق.
- يتغير حجم الساحة تلقائياً حسب عدد المشاركين عند بدء الجولة.
- لكل لاعب لون قلم مستقل، وتبقى آثاره حتى نهاية الجولة.
- الاصطدام بخط لاعب آخر أو حدود الساحة يؤدي إلى الخروج المؤقت؛ لمس اللاعب لخطه هو لا يحتسب اصطداماً.
- فرصتا إنقاذ لكل لاعب عبر سؤال من الرياضيات أو الإنجليزي أو الاجتماعيات أو العلوم، بمهلة 20 ثانية.
- رابط الدعوة يفتح الموقع ويحاول إدخال اللاعب إلى الغرفة مباشرة.

## ملاحظات
هذه نسخة أولية قابلة للعب والاختبار. يفضّل اختبارها مع مجموعة صغيرة أولاً. لا تستخدم ذاكرة الخادم الحالية لتشغيل عدة نسخ متوازية؛ يلزم مخزن مشترك مثل Redis إذا توسع الاستضافة إلى أكثر من نسخة.
